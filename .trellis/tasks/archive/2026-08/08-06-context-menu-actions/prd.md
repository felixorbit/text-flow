# 节点与连线右键操作

## Goal

让用户直接在画布中的节点或连线上通过右键菜单执行上下文操作，减少先选中目标再移动到顶部工具栏操作的步骤。

## Background

- 画布由 React Flow 11 驱动，节点与连线均支持选中。
- 当前删除入口包括 `Backspace` / `Delete` 键和顶部的 “Delete Selected” 按钮。
- React Flow 已提供节点和连线的上下文菜单事件，可在现有受控 `nodes` / `edges` 状态上实现删除。

## Requirements

- 节点和连线均可通过右键打开位置明确的上下文菜单。
- 首版菜单仅提供“删除”，菜单结构应便于后续增加其他操作。
- 右键目标未被选中，仅删除该目标；右键目标已处于多选选区中，删除整个选区。
- 删除节点时，同时移除与该节点连接的所有连线，避免悬空连接。
- 删除连线时，仅移除目标连线，不影响两端节点。
- 菜单可通过点击菜单外部、点击画布空白处或按 `Escape` 关闭。
- 菜单不得超出可视画布边界，并应保持与现有界面一致的视觉与交互反馈。
- 现有键盘删除和顶部 “Delete Selected” 功能继续工作。

## Acceptance Criteria

- [ ] 右键点击任一节点时，在指针附近显示该节点的上下文菜单，并阻止浏览器默认菜单。
- [ ] 右键点击任一连线时，在指针附近显示该连线的上下文菜单，并阻止浏览器默认菜单。
- [ ] 从菜单删除节点后，该节点及其所有关联连线从画布移除。
- [ ] 从菜单删除连线后，该连线移除而两端节点保留。
- [ ] 右键未选中的目标执行删除时，只删除该目标；右键多选中的目标执行删除时，删除选区内全部节点与连线。
- [ ] 点击菜单外部或按 `Escape` 后菜单关闭，不执行操作。
- [ ] 菜单靠近画布边缘打开时仍完整可见。
- [ ] 键盘删除和顶部删除按钮没有行为回归。
- [ ] `npm run lint` 与 `npm run build` 通过。

## Out of Scope

- 删除确认弹窗与撤销/恢复机制。
- 移动端长按菜单。
- 除“删除”之外的其他右键操作。
